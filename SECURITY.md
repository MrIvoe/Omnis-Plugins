# Security Policy

This repo shares a security policy with the main
[Omnis](https://github.com/MrIvoe/Omnis) repository — see
[Omnis's SECURITY.md](https://github.com/MrIvoe/Omnis/blob/main/SECURITY.md)
for how to privately report a vulnerability, and
[docs/PLUGIN_SECURITY.md](https://github.com/MrIvoe/Omnis/blob/main/docs/PLUGIN_SECURITY.md)
for the trust model these bundled plugins operate under (full platform
access, no sandbox — reviewed the same as any other Omnis code).

Please don't open a public issue for a security problem in any bundled
plugin here — report it through
[Omnis's Security tab](https://github.com/MrIvoe/Omnis/security)
instead, the same as an issue in the Core.
